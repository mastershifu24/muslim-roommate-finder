# 📸 Quick Guide: Add Real Muslim Photos (5 Minutes)

## Option 1: Pexels (FREE - No Login Required)

### Step 1: Find Photos
Go to these direct links:

**For Women (Hijabi):**
1. https://www.pexels.com/search/muslim%20woman%20hijab/
2. Click any professional-looking photo
3. Click "Free Download" → Select "Medium" size
4. Save as: `fatima_ali_profile.jpg` or `aisha_mohammed_profile.jpg`

**For Men:**
1. https://www.pexels.com/search/muslim%20man/
2. Click any professional-looking photo
3. Click "Free Download" → Select "Medium" size
4. Save as: `ahmed_hassan_profile.jpg`, `omar_ibrahim_profile.jpg`, or `yusuf_ahmed_profile.jpg`

### Step 2: Add to Project

**Windows (PowerShell):**
```powershell
# Copy photos to project
Copy-Item ~/Downloads/*_profile.jpg muslim-roommate-finder/media/profile_photos/

# Commit and push
cd muslim-roommate-finder
git add media/profile_photos/
git commit -m "Add real Muslim profile photos"
git push
```

**Mac/Linux:**
```bash
# Copy photos to project
cp ~/Downloads/*_profile.jpg muslim-roommate-finder/media/profile_photos/

# Commit and push
cd muslim-roommate-finder
git add media/profile_photos/
git commit -m "Add real Muslim profile photos"
git push
```

### Step 3: Wait 2 Minutes
Render will auto-deploy. Then visit:
**https://muslim-roommate-finder.onrender.com/profiles/**

✨ **Photos will show automatically!**
